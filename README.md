 Project Overview

The World Happiness Report 2019 project focuses on analyzing happiness levels across different countries using Python. It explores how economic and social factors, such as GDP per capita, family support, health, freedom, generosity, and corruption, are related to people's happiness.

The main objective of this project is to understand which factors contribute to a country's happiness score and compare happiness rankings across countries.

 Project Objectives

Analyze happiness scores of different countries.

Identify the happiest and least happy countries.

Understand the relationship between GDP per capita and happiness.

Analyze the impact of social support, health, and freedom.

Calculate statistical measures such as mean, maximum, minimum, and correlation.

Perform Exploratory Data Analysis (EDA) using Python.

 Dataset Information

2.Total Records: 155

4.Data Type: Numerical and categorical data
